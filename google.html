Google connections

中文版

TaroBird is a self-hosted AI workspace. Google access is optional and is set up by the owner of your host. Available operations depend on the tools installed on that host and the permissions you grant. A Google connection is not required to use ordinary TaroBird chats.

What the tools can do

  • Gmail: a separately configured mail tool, such as Google Workspace CLI (gws), can find and read messages, summarize requested mail, prepare drafts, send mail, and manage labels or messages when you request those actions.
  • Calendar: a separately configured calendar tool can find events, check your schedule, and create, update or delete events at your request.
  • Google Docs: TaroBird's document export can create a Google document from a response or update an exported document after the host owner configures Google Docs authorization.

These are distinct connections. Granting access to one does not automatically connect the others. An OAuth app name belongs to the project used by your configured tool; older developer configurations may show gws-client. Public OAuth verification is not yet complete. This page does not claim Google approval.

Before connecting

Read the Google data section of our privacy policy. Review the account and permissions shown by Google. Mail and calendar content returned to an AI agent may be included in the conversation and sent to the model provider selected for that agent. Do not connect an account unless you trust the host operator and have reviewed that provider's data-use and retention settings.

Use Google data only for the user-requested feature. Do not use it for advertising, resale, or training general-purpose AI models. Cloud processing must meet Google's Limited Use requirements; a provider's availability in TaroBird does not establish that it is eligible to receive Google data.

The planned public integration will support local inference or reviewed cloud API configurations only. Its processing restrictions and Google data-access review are not yet complete. Existing self-configured tools must not be treated as an approved public connection or as proof that every selectable model can process Google data.

Google website sign-in and app authorization

Google website sign-in establishes a session in the browser where you sign in. It does not authorize Gmail or Calendar APIs. Google OAuth authorization must take place in a supported external browser, such as your normal Chrome or Safari, not in an application-controlled embedded browser.

Continue using a Google website in that external browser. Its cookies and signed-in session are not copied into TaroBird. For an app authorization flow, follow the setup tool's instructions and its callback; Google Docs host authorization must be completed on the computer running that host.

Disconnect and remove data

  1. In your Google Account's third-party connections, find the app used for authorization and remove its access.
  2. Disconnect the corresponding host tool. For Google Docs, the host owner can run tarobot gdocs logout. For gws, use gws auth logout. Other connectors have their own disconnect controls.
  3. Remove saved conversation copies, downloaded files and backups from the host and devices where they were stored. Revoking access does not erase earlier copies, Google mailbox items, or Google documents.
  4. Use the relevant browser's Clear browsing data controls to remove cookies, website data and browsing history. Browser sign-out and API revocation are separate.

For help, see Support. Never put emails, tokens, authorization codes or connection details in a public issue.

Google 连接说明

TaroBird 是自托管 AI 工作区。Google 连接是可选功能，由主机所有者配置；实际操作取决于主机安装的工具及你授予的权限。普通聊天不要求连接 Google。

Gmail、日历：通过单独配置的工具（例如 gws）按你的要求查找和读取邮件、起草或发送邮件、管理邮件和标签，以及查询、创建、修改或删除日程。Google 文档：主机配置 Google Docs 授权后，可以把回答导出为文档或更新已导出的文档。三者的授权互相独立。

Google 授权页面的应用名称由所用项目决定，早期开发配置可能显示 gws-client。公开 OAuth 验证尚未完成，本页面不表示 Google 已批准本应用。

连接前请阅读Google 数据隐私说明，核对 Google 显示的账号和权限。工具读回的邮件或日程可能进入对话，并发送给该 Bot 使用的模型服务商。请先确认主机运营者、模型服务商及其数据使用和保留设置。Google 数据只能用于用户请求的功能，不得用于广告、转售或通用 AI 模型训练；服务商出现在 TaroBird 的可选列表中，并不意味着它已符合 Google 数据处理要求。

计划中的公开集成仅支持本地推理或经核验的云端 API 配置，相关限制措施和 Google 数据权限审核尚未完成。当前自行配置的工具不等于已获审核的公开连接，也不表示所有可选模型都能处理 Google 数据。

内置浏览器与 Google 登录

登录 Google 网页和授权 Gmail／日历 API 是两件事。Google OAuth 授权需要使用支持的外部浏览器，例如你常用的 Chrome 或 Safari。Google 网页请在该浏览器里继续使用，登录状态和 Cookie 不会复制回 TaroBird。应用授权则按配置工具的提示和回调完成；主机的 Google Docs 授权须在运行该主机的电脑上完成。

断开与删除

先在 Google 账号的第三方连接中移除对应应用的访问权限，再断开主机工具。Google Docs 使用 tarobot gdocs logout，gws 使用 gws auth logout。按需清理主机、设备、下载目录和备份中的已保存内容。撤销授权不会删除之前保存的副本，也不会删除 Google 中的邮件或文档。网页 Cookie、网站数据和历史记录通过对应浏览器的“清除浏览数据”单独管理。
